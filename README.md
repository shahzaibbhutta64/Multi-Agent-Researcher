# Multi-Agent AI Research Application

An autonomous multi-agent research team powered by **CrewAI**, **Groq Llama-3.3-70B**, and **Streamlit**.

## Features
- **4 Autonomous Agents:** General Researcher, Technical Researcher, Fact Checker, and Report Writer.
- **Live Search:** Automated DuckDuckGo web querying.
- **Secure Secret Management:** Integrates natively with Streamlit Secrets.
- **Export Options:** Download complete structured reports directly as Markdown.
